# Agreed licensing policy

Decision: 11 November 2026.

- Original ontology, vocabulary, registry metadata, examples, and project documentation: CC0-1.0.
- Original software, scripts, and executable tooling: MIT.
- Third-party material retains its upstream terms; referencing, indexing, fetching, or conversion does not relicense it.

## Voluntary attribution request

Attribution is appreciated but not required. When practical, please credit the Agent Role Ontology project and link to https://github.com/GeniusTechnoMystic/agent-role-ontology. This request is not a condition of use and does not modify the CC0-1.0 dedication.

## Implementation still required

Add the unmodified standard CC0-1.0 and MIT texts and a clear file/directory licensing map before distributing a licensed release. This policy records the agreed scope; it is not a substitute for those standard texts. The initial checkpoint contains documentation only.

Do not assume attribution is optional for upstream works. AgentO's project page advertises CC-BY-4.0: inspect exact artifact terms before copying or deriving material. Evaluate external references, alignments, and separately attributed imports rather than declaring the combined material CC0. Record licence evidence by source and revision.
